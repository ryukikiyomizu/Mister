## About

Mister helps you inspect, preview, and organize files you already have locally.
It is designed for personal preservation and research workflows.

## Download

Ready-to-run Windows builds will be available from
[Releases](https://github.com/ryukikiyomizu/Mister/releases).

## Notes

- Windows x64
- Works offline
- Does not include third-party content
- Use only with files you are authorized to access
